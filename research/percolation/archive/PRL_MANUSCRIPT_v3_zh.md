# 站点渗流阈值的指数维度衰减

> **论文草稿** — Nature风格格式
> **日期**: 2026-10-04
> **数据**: 94个晶格, d = 2–13, z = 3–146, g ∈ {3, 4, 6}

---

## 摘要

渗流阈值编码了无序介质中长程输运所需的连通性，但目前尚无可统一预测不同维度、配位数和环拓扑结构晶格的单一解析表达式。Bethe近似给出了树状图的 p_c = 1/(z−1)，为自然零阶估计，但无法捕捉有限环产生的修正。本文发现，Bethe极限的主导修正随空间维度呈指数衰减而非幂律衰减。通过在 d = 2 到 13 的94个晶格上拟合一个四参数饱和修正模型，我们实现了全局平均绝对百分比误差8.1%，高维超立方子集 (d ≥ 8) 仅为2.8%，而幂律模型在该子集上误差高达20.8%。指数衰减率定义了特征维度 d* ≈ 3.0，超过此值有限维修正变得可忽略，与上临界维度 d_c = 6 的图像定性一致。配位数饱和尺度 z₀ ≈ 10 与维度无关，表明当每个格点拥有约10个近邻时，局部连通环境达到普适的交叉点。这些结果为不同维度的渗流阈值提供了紧凑的解析框架，并暗示指数修正可能推广至上临界维度附近的其他阈值现象。

---

## 引言

渗流阈值量化了连接簇首次跨越晶格的临界占据概率。该阈值控制着多孔介质中的输运、疾病的传播以及无序网络中刚性的出现。尽管经历了数十年的理论和计算研究，预测不同维度、配位数和环结构晶格的渗流阈值的单一闭合表达式仍未获得。

Bethe近似 p_c = 1/(z−1) 捕获了无穷树的极限，提供了有用的基线。然而对于任何有限维晶格，闭合环的存在都会修正阈值。其挑战在于刻画这种修正如何依赖于晶格结构。

先前的工作提出了按维度或配位数幂律标度的修正形式，通常针对特定晶格族进行校准。这些表达式在其训练域内表现尚可，但在域外系统性地失效，尤其在高维区域——那里修正应以快速的方式趋于平均场行为。此前没有模型能够捕获低维晶格（环效应占主导）与高维区域（Bethe近似精确成立）之间的交叉行为。

本文提出了一个四参数公式，在维度2到13、配位数3到146的94个晶格上捕获渗流阈值。核心发现是：维度修正呈指数衰减而非幂律衰减，使高维预测误差降低了一个量级，同时保持了低维的精度。

---

## 结果

### 四参数公式捕获94个渗流阈值

我们汇集了94个站点渗流阈值的文献数据集，涵盖维度 d = 2 到 13，配位数 z = 3 到 146，girth g ∈ {3, 4, 6}（附表1）。数据集包括经典精确可解晶格、最近的高维超立方结果以及扩展的二维近邻连接变体。

从Bethe归一化阈值 R = p_c(z − 1) 出发，我们测试了十余种候选函数形式来描述修正 ΔR = R − 1。最优模型的形式为：

$$p_c = \frac{1}{z-1}\left[1 + \frac{a \cdot e^{-\alpha d}}{g^\gamma}\left(1 - e^{-z/z_0}\right)\right]$$

四个拟合参数为：振幅 a = 12.33，指数衰减率 α = 0.337，girth指数 γ = 0.848，配位数饱和尺度 z₀ = 9.62。

该公式在全部94个晶格上实现了8.1%的平均绝对百分比误差（MAPE），R² = 0.973，AIC = −668.3（图1a）。十折交叉验证MAPE为 8.5% ± 0.1%，表明模型可以推广到未见过的晶格构型而无过拟合。中位误差为7.1%，10个晶格（11%）超过了15%的误差阈值。

### 指数衰减在高维优于幂律替代方案

为验证指数形式的必要性，我们将其与结构完全相同的幂律模型进行对比：p_c = (z−1)⁻¹[1 + a·d⁻ᵝ·g⁻ᵞ·(1 − e⁻ᶻ⁄ᶻ⁰)]。幂律模型全局MAPE为8.8%，但在高维超立方晶格上灾难性失效：d ≥ 8时误差20.8%，而指数模型仅2.8%（图2，表1）。

| 维度 | 指数模型误差 | 幂律模型误差 |
|------|------------|------------|
| d = 2 | 8.6% | 8.6% |
| d = 3 | 5.9% | 2.5% |
| d = 4–7 | 14.0% | 16.0% |
| **d ≥ 8** | **2.8%** | **20.8%** |

其代价是d = 3误差从2.5%适度增加到5.9%，以换取高维的显著改善。模型选择标准一致支持指数形式：AIC −668.3 vs −667.4，BIC −658.1 vs −657.2。我们测试了12个替代模型变体，包括维度依赖衰减率、girth特异性修正和维度-girth交叉项。没有一个在AIC或交叉验证MAPE上优于四参数基线。

### 特征维度 d* ≈ 3.0

指数衰减率 α = 0.337 定义了特征维度 d* = 1/α ≈ 3.0，即修正衰减到其 d = 0 值的 e⁻¹ ≈ 37% 的尺度。在 d = 2d* ≈ 6 处，修正幅度降至13%；在 d = 3d* ≈ 10 处，降至5%以下。这种有限维效应的快速抑制与渗流的上临界维度 d_c = 6 定性一致——在 d_c 以上，临界指数取平均场值。

关键维度的指数值为：exp(−α·2) = 0.51，exp(−α·3) = 0.36，exp(−α·6) = 0.13，exp(−α·10) = 0.03，exp(−α·13) = 0.01。对于 d > 6，修正变得可忽略，与平均场行为的出现一致。

### 普适的饱和尺度 z₀ ≈ 10

饱和函数 S(z) = 1 − exp(−z/z₀)，z₀ = 9.62，捕获了从树状晶格（额外近邻强烈影响 p_c）到高度连通晶格（局部环境有效完备）的交叉。关键的是，该饱和尺度与维度无关：相同的 z₀ 同时适用于 d = 2 和 d = 13。

物理解读：当每个格点拥有约10个近邻时，局部连通环境变得饱和。超出 z₀ 的额外近邻对渗流阈值的影响递减，修正仅通过预因子 a·exp(−αd)/g^γ 依赖于维度和girth。

### 系统性残差模式与模型局限

有符号残差的分析揭示了两个系统性特征。第一，d = 3子集（18个晶格）呈现−5.2%的平均残差，其中17个晶格被高估。第二，Malarz (2023) 的sq系列——具有扩展近邻连接的二维方格子晶格，girth g = 3——在 z = 8–12 时呈现10–29%的误差。

我们探索了模型变体能否消除这些模式。一个五参数模型（d ≤ 3时α₁ = 0.39，d ≥ 4时α₂ = 0.34）将d = 3误差降至3.5%，但恶化了AIC（−667.0 vs −668.3）、交叉验证MAPE（8.25% vs 8.50%）和高维误差（d ≥ 8时3.4% vs 2.8%）。没有任何变体在不损害其他类别的情况下改善了sq系列误差，这表明这些残差模式反映了(z, d, g)描述符空间对某些二维拓扑的固有限制，或底层蒙特卡洛估计的系统性不确定度。

## 讨论

本工作的核心结果是：指数维度衰减而非幂律标度，捕获了站点渗流阈值对Bethe近似的主导修正。这一发现具有实践和概念层面的意义。

在实践层面，四参数公式提供了一个单一表达式，能在六个数量级的配位数范围（z = 3到146）和超过十一倍的维度范围（d = 2到13）上以平均8%的误差预测渗流阈值。对于高维超立方晶格——此前模型失败达20%——指数模型实现了3%的精度。这使得对蒙特卡洛模拟计算成本高昂的晶格构型进行快速阈值估计成为可能。

在概念层面，指数形式可以通过晶格上闭合环的统计来理解。Bethe近似假设无环的树状图。在 d 维中，随机游走返回原点的概率按 (2d)⁻¹ 标度，所有环修正的累积权重随维度快速衰减。指数形式 e^{−αd} 自然地编码了这种快速抑制，而较慢的幂律衰减 d⁻ᵝ 则系统性地高估了大维度的修正。

我们强调，指数形式是通过比较十余种候选模型经验性地识别的，而非从第一原理推导得出。上述物理论证提供了定性动机，但不构成推导。参数 (a, α, γ, z₀) 是否能从晶格格林函数或集团展开技术获得，仍是一个开放问题。

以下几点局限需要指出。该公式适用于具有均匀配位数的规则晶格上的站点渗流；向键渗流、非规则晶格或非均匀配位数晶格的推广未经验证。d = 3的系统性偏差（平均残差−5.2%）和 g = 3 时sq系列的残差表明，公式在这些区域可能不可靠。数据集中的girth值仅限于{3, 4, 6}，其他girth值的性能未经检验。最后，饱和尺度 z₀ ≈ 10 的物理解释及其与渗流临界指数的潜在联系仍有待建立。

## 方法

### 数据集构建

我们从已发表文献中收集了94个晶格构型的站点渗流阈值（附表1）。数据集包括：经典二维晶格的精确可解阈值（三角、蜂窝、方格、Kagome和Archimedean晶格）、d = 4到d = 13超立方晶格的高精度蒙特卡洛结果、近邻壳层连接直到第九壳层的扩展三维晶格、具有扩展近邻连接的二维晶格（Malarz 2023, 2024），以及三维Kagome推广。

对每个晶格，我们记录了配位数 z、空间维度 d、girth g（最短环长度）和报告的渗流阈值 p_c。所有阈值均为站点渗流值。文献中存在多个估计值时，我们选取最新或最高精度的值。

### 模型拟合

我们使用Nelder–Mead单纯形算法最小化预测与观测 p_c 值的残差平方和，进行200次随机初始化以避免局部极小值。最终模型的四个参数范围为：a ∈ [5, 30]，α ∈ [0.05, 0.5]，γ ∈ [0.3, 1.5]，z₀ ∈ [3, 20]。最佳拟合参数在所有成功初始化间一致。

### 模型选择

我们使用赤池信息量准则（AIC = n·ln(SSR/n) + 2k）和贝叶斯信息量准则（BIC = n·ln(SSR/n) + k·ln(n)）比较模型，其中 n = 94 为晶格数，SSR 为残差平方和，k 为自由参数数。较低值表明在惩罚复杂度后模型更优。四参数指数模型在所有测试变体中被AIC和BIC共同选中。

### 交叉验证

十折交叉验证将94个晶格分为十个近似等大的折，在九折上拟合模型并在留出折上评估。该过程以10个不同的随机划分重复，以估计交叉验证MAPE的均值和标准误。

### Bootstrap稳定性

我们通过100次有放回的Bootstrap重采样评估参数稳定性。每次重采样以10次随机初始化重新拟合模型。衰减率 α 的变异系数（CV = 标准差/均值）为14.8%，饱和尺度 z₀ 为17.6%，表明这些参数由数据稳健地确定。

## 补充信息

### Python实现

```python
import numpy as np

def percolation_threshold(z, d, g):
    """
    预测站点渗流阈值。

    参数
    ----------
    z : int 或 array
        配位数
    d : int 或 array
        空间维度
    g : int 或 array
        Girth（最短环长度）

    返回
    -------
    pc : float 或 array
        渗流阈值
    """
    a, alpha, gamma, z0 = 12.33, 0.337, 0.848, 9.62
    correction = (a * np.exp(-alpha * d) / g**gamma) * (1 - np.exp(-z / z0))
    return (1 + correction) / (z - 1)
```
