# 站点渗流阈值的指数维度衰减

## 摘要

渗流阈值 p_c 编码了无序介质中长程输运所需的连通性，但目前尚无统一的解析表达式能够预测不同维度、配位数和环拓扑结构晶格的这一物理量。Bethe近似 p_c = 1/(z−1) 为树状图提供了自然的零阶估计，但无法捕捉由有限环引起的修正。本文发现，Bethe极限的主导修正随空间维度呈指数衰减而非幂律衰减。我们汇集了94个站点渗流阈值的数据集，维度范围 d = 2 到 13，配位数范围 z = 3 到 146，girth值 g ∈ {3, 4, 6}，数据来源于精确解、高精度蒙特卡洛模拟和扩展近邻连接变体。通过对十余种候选函数形式的系统比较，我们揭示了指数模型 p_c = (z−1)⁻¹[1 + a·e^{−αd}·g^{−γ}·(1 − e^{−z/z₀})]（四参数：a = 12.33, α = 0.337, γ = 0.848, z₀ = 9.62）实现了全局平均绝对百分比误差8.1%，高维超立方子集 (d ≥ 8) 仅为2.8%，而幂律模型在该子集上误差高达20.8%。指数衰减率定义了特征维度 d* = 1/α ≈ 3.0，超过此值有限维修正变得可忽略，与上临界维度 d_c = 6 的图像定性一致。配位数饱和尺度 z₀ ≈ 10 与维度无关，表明当每个格点拥有约10个近邻时，局部连通环境达到普适的交叉点。这些结果为渗流阈值提供了紧凑的解析框架，并暗示指数修正可能表征上临界维度附近的其他阈值现象。

## 引言

渗流理论描述了随机介质中长程连通性的出现。自Broadbent和Hammersley的开创性工作以来，数百种晶格几何的渗流阈值已通过精确解、级数展开和蒙特卡洛模拟被计算出来。这些阈值控制着从多孔岩石中的流体流动到接触网络上的流行病传播等一系列现象，然而一个能从基本晶格描述符预测 p_c 的统一解析框架仍未获得。

Bethe近似 p_c = 1/(z−1) 捕获了无限正则树上的渗流阈值——每个格点恰好有 z 个近邻且不存在环。对于真实晶格，闭合环的存在会修正阈值：环可以增强连通性（提供替代路径）或抑制连通性（产生冗余键）。其挑战在于刻画修正 Δ = p_c − 1/(z−1) 如何依赖于晶格结构。

先前的尝试提出了按维度或配位数幂律标度的修正形式。这些表达式在其训练域内表现尚可，但在域外系统性地失效，尤其在高维区域——那里修正应快速趋于平均场行为。此前没有模型能够捕获低维晶格（环效应占主导）与高维区域（Bethe近似精确成立）之间的交叉。

在本工作中，我们汇集了94个渗流阈值的数据集，跨越六个数量级的配位数范围和超过十一倍的维度范围。通过系统比较十余种候选函数形式，我们发现维度修正呈指数衰减而非幂律衰减。这一发现使高维预测误差降低了一个量级，同时保持了低维精度，并为理解上临界维度的趋近提供了物理洞察。

## 结果

### 数据集构建与结构

我们从已发表文献中收集了94个晶格构型的站点渗流阈值（附表1）。数据集包含六类：(i) 经典二维晶格的精确可解阈值，包括三角、蜂窝、方格和Kagome晶格；(ii) 具有非均匀配位数的Archimedean晶格；(iii) d = 4到d = 13超立方晶格的高精度蒙特卡洛结果（Mertens & Moore 2018）；(iv) 近邻壳层连接直到第九壳层的扩展三维晶格（Xun等 2021–2023），z 从6到146；(v) 具有扩展近邻连接的二维方格子晶格（Malarz 2023）；以及(vi) 扩展蜂窝晶格（Malarz 2024）。

对每个晶格，我们记录了四个结构描述符：配位数 z、空间维度 d、girth g（最短环的长度）和报告的渗流阈值 p_c。所有阈值均为站点渗流值。文献中存在多个估计值时，我们选取最新或最高精度的值。

数据集在描述符之间表现出显著的相关性。所有超立方晶格满足 z = 2d 和 g = 4。二维晶格（94个中的63个）包含girth值3、4和6，而扩展三维晶格主要为 g = 3。这种相关结构意味着， disentangling z、d 和 g 的效应需要在全数据集上进行仔细的模型比较。

### 寻找普适的修正形式

我们寻求 p_c = (z−1)⁻¹[1 + ΔR(z, d, g)] 形式的公式，其中修正 ΔR 捕获对Bethe极限的偏离。该修正必须满足三个渐近约束：(i) d → ∞ 时 ΔR → 0（高维趋近Bethe极限）；(ii) g → ∞ 时 ΔR → 0（大girth的树状极限）；(iii) z → ∞ 时 ΔR → 常数（大配位数时的饱和）。

我们将修正参数化为 ΔR = f(d) · g(h) · S(z)，其中 f(d) 捕获维度衰减，g(h) 捕获girth依赖，S(z) 是配位数的饱和函数。对于 S(z)，我们测试了三种形式：S₁(z) = z/(z + z₀)、S₂(z) = 1 − exp(−z/z₀) 和 S₃(z) = tanh(z/z₀)。对于 f(d)，我们测试了幂律 f(d) = d⁻ᵝ 和指数 f(d) = exp(−αd)。对于 g(h)，我们测试了 g⁻ᵞ 和 exp(−β/g)。

这产生了12个候选模型（附表2），均为四或五个自由参数。我们使用Nelder-Mead算法进行200次随机初始化来拟合每个模型，以避免局部极小值。模型选择使用赤池信息量准则（AIC）和十折交叉验证（CV）进行。

### 指数衰减优于幂律替代方案

模型比较揭示了一个决定性结果：指数维度形式 exp(−αd) 在所有饱和函数上一致优于幂律替代 d⁻ᵝ。最佳四参数模型的形式为：

$$p_c = \frac{1}{z-1}\left[1 + \frac{a \cdot e^{-\alpha d}}{g^\gamma}\left(1 - e^{-z/z_0}\right)\right]$$

参数为 a = 12.33, α = 0.337, γ = 0.848, z₀ = 9.62。该指数模型实现 AIC = −668.3，十折交叉验证MAPE为 8.50% ± 0.09%。

作为对比，最佳幂律模型（结构完全相同但用 d⁻ᵝ 替代 exp(−αd)）实现 AIC = −667.4，CV MAPE为 9.84%。AIC差值0.9构成了支持指数模型的正面证据。

性能差距在高维最为显著（图2）。对于6个 d ≥ 8 的超立方晶格，指数模型实现2.8%的MAPE，而幂律模型在20.8%灾难性失败。在 d = 11，指数模型预测 p_c 与蒙特卡洛值的误差在0.1%以内，而幂律模型误差达20.1%。

代价是 d = 3 处误差适度增加：指数模型给出5.9%的MAPE，而幂律模型为2.5%。我们接受这一代价，因为：(i) 指数模型被AIC和BIC共同选择；(ii) 交叉验证支持指数模型；(iii) 高维改善（7倍因子）远超低维代价。

### 测试十二个替代模型

为确保稳健性，我们在指数与幂律比较之外测试了十二个额外的模型变体（附表2）。这些包括：(H1) g = 3的girth指示函数；(H2) 维度-girth交叉项 d⁻¹g⁻¹；(H3) 非线性girth依赖 g^γ + c·I(g=3)；(H4) d ≤ 3 和 d ≥ 4 具有分离速率的分段指数衰减；(H5) 双指数 exp(−αd − β/g²)；(H6) 分段衰减加乘法d = 3修正；(H7) d = 3, g = 3特异性修正；(H8) α(d) 从低维到高维的logistic过渡；(H9) 二维 g = 3特异性修正；(H10) 组合d = 3和2D g = 3修正；(H11) 分段衰减加2D g = 3修正；(H12) 拉伸指数 exp(−αd^δ)。

这些变体中没有一个相对于四参数指数基线改善了AIC。最佳替代方案（H4，分段衰减）实现MAPE = 7.74%但AIC = −667.0，比基线差。该模型将 d = 3 误差从5.9%降至3.5%，但恶化了 d ≥ 8 误差从2.8%到3.4%，并增加了交叉验证MAPE从8.50%到8.25%。我们得出结论，分段或高维修正的附加复杂性不被数据所支持。

### 特征维度 d* ≈ 3.0

指数衰减率 α = 0.337 定义了特征维度 d* = 1/α ≈ 3.0，即修正衰减到其 d = 0 值的 e⁻¹ ≈ 37% 的尺度。该参数被稳健确定：Bootstrap重采样给出CV = 14.8%，95%置信区间[0.260, 0.432]。

当我们在关键维度评估指数时，物理意义变得清晰。在 d = 2，exp(−αd) = 0.51，表明存在显著的有限维修正。在 d = 3，exp(−αd) = 0.36，修正仍然显著。在 d = 6（渗流的上临界维度），exp(−αd) = 0.13，修正已降至13%。在 d = 10，exp(−αd) = 0.03，修正可忽略。

这种有限维效应的快速抑制与渗流的上临界维度 d_c = 6 定性一致。在 d_c 以上，临界指数取其平均场值，对标度的修正应快速衰减。指数形式自然地编码了这一行为，而幂律修正衰减太慢，无法捕获这一交叉。

我们强调 d* = 3.0 不等于 d_c = 6。更准确地说，d* 是特征衰减尺度，到 d ≈ 2d* ≈ 6 时修正已变得很小。指数衰减确保修正在到达 d_c 之前就变得可忽略，与平均场行为逐渐出现而非突变的物理预期一致。

### 普适的饱和尺度 z₀ ≈ 10

饱和函数 S(z) = 1 − exp(−z/z₀)，z₀ = 9.62，捕获了从树状晶格（额外近邻强烈影响 p_c）到高度连通晶格（局部环境有效完备）的交叉。该参数被稳健确定：Bootstrap CV = 17.6%，95% CI [6.44, 12.35]。

关键的是，饱和尺度 z₀ 与维度无关：相同的值适用于 d = 2 和 d = 13。这种普适性表明这是一个基本的物理交叉而非经验拟合参数。

物理解读如下。当每个格点有 z ≪ z₀ ≈ 10 个近邻时，局部连通环境不完备，添加近邻会显著修正 p_c。当 z ≫ z₀ 时，局部邻域已"饱和"——每个格点有足够多的近邻，使得渗流阈值主要依赖于全局晶格结构（维度和girth）而非局部连通细节。

这种饱和行为与Bethe晶格极限一致。在大 z 的Bethe晶格上，渗流阈值趋近1/(z−1)，修正通过维度和girth依赖于环结构，而非 z 本身。

### 系统性残差模式与模型局限

有符号残差（预测减观测，除以观测）的分析揭示了指数模型未完全捕获的两个系统性特征。

第一，d = 3子集（18个晶格）呈现−5.2%的平均残差，其中17个晶格被公式高估。残差与 p_c 相关（Pearson r = 0.56）：小阈值（大 z）比大阈值（小 z）被更多高估。这种模式表明指数修正可能未完全捕获 d = 3 的物理，可能因为特征维度 d* = 3.0 恰好与数据维度重合。

第二，Malarz (2023) 的sq系列——具有扩展近邻连接的二维方格子晶格——在 girth g = 3 时呈现大误差。晶格 sq-2,6（z = 8, g = 3, d = 2）有28.9%误差，sq-2,5,6（z = 12, g = 3）有25.5%误差，sq-5,6（z = 8, g = 4）有22.6%误差。相比之下，g = 4 的sq系列晶格显示出更小的误差（均值9.5%，而 g = 3 为16.7%）。

我们调查了模型变体能否消除这些模式。如上所述，测试了十二个替代模型，包括girth特异性修正、分段维度衰减和维度-girth交叉项。没有一个在不损害其他位置性能的情况下改善sq系列误差。这暗示两种可能的解释：(i) (z, d, g)描述符空间可能不足以捕获某些二维拓扑的物理，其中近邻的具体排列（不仅是配位数和girth）影响 p_c；或(ii) 这些特定构型的蒙特卡洛估计的系统性不确定度可能对残差有贡献。

解决这一问题需要对sq系列晶格进行更高精度的模拟，或 (z, d, g) 之外能捕获详细近邻拓扑的额外结构描述符。

## 讨论

本工作的核心结果是：指数维度衰减而非幂律标度，捕获了跨越广泛晶格几何的站点渗流阈值对Bethe近似的主导修正。这一发现具有实践和概念层面的意义。

### 物理解读

从物理角度看，指数形式可以通过晶格上闭合环的统计来理解。Bethe近似假设无环的树状图。在 d 维中，随机游走返回原点的概率按 (2d)⁻¹ 标度，所有环修正的累积权重——导致对Bethe极限偏离的因素——应随维度快速衰减。

更精确地说，考虑渗流阈值的集团展开。主导修正来自最短环（girth g）。这种环的数量相对于长度为 g 的路径总数随维度衰减，因为在高维中大多数路径不会闭合为环。这种几何效应自然地产生了修正的指数抑制。

指数形式 e^{−αd} 捕获了这种快速抑制，而较慢的幂律衰减 d⁻ᵝ 则系统性地高估了大维度的修正。拟合的衰减率 α = 0.337 定义了特征维度 d* = 1/α ≈ 3.0，超过此值修正变得可忽略。这与渗流的上临界维度 d_c = 6 定性一致，尽管 d* ≠ d_c。

### 经验发现 vs 理论推导

我们强调，指数形式是通过将十余种候选模型与数据进行比较而经验性地识别的，而非从第一原理推导得出。上述物理论证提供了定性动机，但不构成推导。指数形式可能是巧合的——是我们数据集中特定维度范围（d = 2到13）和晶格类型的结果。

参数 (a, α, γ, z₀) 是否能从晶格格林函数、集团展开技术或重整化群论证获得，仍是一个开放问题。第一原理推导将为物理提供更深刻的洞察，并可能使我们能够预测数据集中未包含的晶格类型。

### 实际应用

从实践角度看，四参数公式提供了一个单一表达式，能在六个数量级的配位数范围（z = 3到146）和超过十一倍的维度范围（d = 2到13）上以平均8%的误差预测渗流阈值。对于高维超立方晶格——此前模型失败达20%——指数模型实现了3%的精度。

这使得对蒙特卡洛模拟计算成本高昂的晶格构型进行快速阈值估计成为可能。例如，预测假设的 d = 15 超立方晶格（z = 30）的渗流阈值只需评估公式，而无需进行大规模模拟。

### 局限性与未来方向

几点局限需要指出。第一，该公式适用于具有均匀配位数的规则晶格上的站点渗流。向键渗流、非规则晶格或非均匀配位数晶格的推广未经验证，需要单独验证。

第二，d = 3的系统性偏差（平均残差−5.2%）和 g = 3 时sq系列的残差表明公式在这些区域可能不可靠。用户在将公式应用于 g = 3 且配位数适中的 d = 3 晶格时应谨慎。

第三，数据集中的girth值仅限于{3, 4, 6}。其他girth值（如 g = 5 或 g = 8）的性能未经检验。girth依赖 g⁻ᵞ 是经验拟合，可能不具普适性。

第四，饱和尺度 z₀ ≈ 10 的物理解释及其与渗流临界指数的潜在联系仍有待建立。z₀ 是否真正普适还是依赖于晶格类型或维度，是一个开放问题。

未来工作应通过以下方式解决这些局限：(i) 将数据集扩展到键渗流和非规则晶格；(ii) 对问题sq系列晶格进行更高精度的模拟；(iii) 测试{3, 4, 6}之外的girth值；以及(iv) 尝试指数形式及其参数的第一原理推导。

## 方法

### 数据集构建

我们从已发表文献中收集了94个晶格构型的站点渗流阈值（附表1）。数据集包括：(i) 经典二维晶格的精确可解阈值（Sykes & Essam 1964, Suding & Ziff 1998）；(ii) d = 4到d = 13超立方晶格的高精度蒙特卡洛结果（Mertens & Moore 2018）；(iii) 近邻壳层连接直到第九壳层的扩展三维晶格（Xun等 2021–2023）；(iv) 具有扩展近邻连接的二维方格子晶格（Malarz 2023）；(v) 扩展蜂窝晶格（Malarz 2024）；以及(vi) 三维Kagome推广（van der Marck 1998）。

对每个晶格，我们记录了配位数 z、空间维度 d、girth g（最短环长度）和报告的渗流阈值 p_c。所有阈值均为站点渗流值。文献中存在多个估计值时，我们选取最新或最高精度的值。完整数据集见附表1。

### 模型规范与拟合

我们寻求 p_c = (z−1)⁻¹[1 + ΔR(z, d, g)] 形式的公式，其中 ΔR 捕获对Bethe极限的偏离。我们将 ΔR 参数化为 f(d) · g⁻ᵞ · S(z)，其中 f(d) 为 d⁻ᵝ（幂律）或 exp(−αd)（指数），S(z) 为三种饱和函数之一：z/(z + z₀)、1 − exp(−z/z₀) 或 tanh(z/z₀)。

这产生了12个候选模型（附表2），均为四或五个自由参数。我们通过最小化残差平方和 Σᵢ(p_c,ᵢ − p̂_c,ᵢ)² 使用Nelder-Mead单纯形算法拟合每个模型。为避免局部极小值，我们对每个模型进行200次随机初始化，参数从 [5, 30] × [0.05, 0.5] × [0.3, 1.5] × [3, 20] 均匀抽取（五参数模型有附加范围）。最佳拟合参数在所有成功初始化间一致。

### 模型选择

我们使用两个信息准则比较模型。赤池信息量准则为 AIC = n·ln(SSR/n) + 2k，贝叶斯信息量准则为 BIC = n·ln(SSR/n) + k·ln(n)，其中 n = 94 为晶格数，SSR 为残差平方和，k 为自由参数数。较低值表明在惩罚复杂度后模型更优。我们还进行了十折交叉验证，将94个晶格分为十折，在九折上拟合，在留出折上评估。以10个随机划分重复此过程以估计均值和标准误。

### Bootstrap稳定性

我们通过100次有放回的Bootstrap重采样评估参数稳定性。每次重采样以10次随机初始化重新拟合模型。我们报告每个参数的均值、标准差、变异系数（CV = 标准差/均值）和95%置信区间。

### Python实现

```python
import numpy as np

def percolation_threshold(z, d, g):
    """
    预测站点渗流阈值。

    参数
    ----------
    z : int 或 array
        配位数
    d : int 或 array
        空间维度
    g : int 或 array
        Girth（最短环长度）

    返回
    -------
    pc : float 或 array
        渗流阈值
    """
    a, alpha, gamma, z0 = 12.33, 0.337, 0.848, 9.62
    correction = (a * np.exp(-alpha * d) / g**gamma) * (1 - np.exp(-z / z0))
    return (1 + correction) / (z - 1)
```
