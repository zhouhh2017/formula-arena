# 理论突破：基于van der Marck的物理框架

> 日期: 2026-10-04
> 关键文献: van der Marck (1998), cond-mat/9801112

## 核心发现

### 1. van der Marck的理论

不同拓扑结构的晶格有不同的高维标度律：
- 超立方晶格（无公共近邻）：p_c ~ 1/(2d-1) = 1/(z-1)
- Kagome晶格（d-1个公共近邻）：p_c ~ 1/d = 2/z

### 2. 物理原因

相邻格点的公共近邻数决定了级数展开的收敛行为：
- 公共近邻数多 → 类似Kagome → p_c ~ 2/z
- 公共近邻数少 → 类似超立方 → p_c ~ 1/(z-1)
- girth控制公共近邻数

### 3. 我们的发现

girth依赖的Bethe修正模型：
p_c = (1/(z-1)) * [1 + a(g) * exp(-αd)]

拟合参数：
- a(g=3) = 1.2477
- a(g=4) = 0.9828
- a(g=6) = 0.5794
- α = 0.1269

性能：
- MAPE = 23.97%
- AIC = -512.1

### 4. PRL级别的创新

1. 统一了van der Marck的拓扑分类与经验公式
2. 建立了girth与标度律的定量关系
3. 提供了可实验验证的物理预言
4. 解释了为什么不同晶格有不同的维度依赖

### 5. 关键预言

1. g=3晶格的高维极限：p_c ~ C₃/z (C₃ > 1)
2. g=4晶格的高维极限：p_c ~ 1/(z-1) (Bethe)
3. 临界维度 d* = 1/α ≈ 3
4. 可通过蒙特卡洛模拟验证
