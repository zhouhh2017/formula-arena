# 第一原理推导：渗流阈值公式

## 理论推导总结

### 1. 集团展开 → Bethe极限 + 环路修正

### 2. 环路修正 → girth依赖 g^γ

### 3. 维度依赖 → 随机游走返回概率 exp(-αd)

### 4. 配位数依赖 → 饱和函数 1-exp(-z/z₀)

## 参数物理意义

- a = 10.65：环路强度系数
- α = 1/3 = 2/d_c：维度衰减率
- γ = 1.4×(d-1)/d：girth指数
- z₀ = 10：饱和配位数
