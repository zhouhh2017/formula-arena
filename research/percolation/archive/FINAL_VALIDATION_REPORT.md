## 🎯 核心发现

### 发现的标度律

$$p_c = A \cdot z^{-\alpha} \cdot d^{-\gamma} \cdot \left(1 + \frac{B}{g}\right)$$

**原始拟合（17个数据点）**:
- A = 2.281, α = 0.816, γ = 0.736, B = 1.492
- R² = 0.9937, MAE = 0.0121

**新MC数据验证（重新模拟）**:
- A = 2.215, α = 0.909, γ = 0.634, B = 1.945
- R² = 0.9930, MAE = 0.0123
- **标度律稳健！**

## ⚠️ 已发现的问题

### 1. α-B共线性（严重）
- α与B的Jacobian相关性 = -0.944
- 根源：数据集中z和g不独立变化
  - 所有z≥8的晶格都是g=4
  - g=3只出现在2D晶格
  - g=6只有2个低z晶格

**后果**: α和B无法独立确定，但它们共同决定的预测值是准确的

### 2. 数据/参数比偏低
- 17个数据点，4个参数
- 比率 = 4.25 < 10（经验规则）
- 统计功效不足

### 3. 高维晶格系统性偏差
- d=7: 残差 +2.7%
- d=8: 残差 +5.9%
- d=9: 残差 +8.9%
- 可能暗示d-g交互效应

### 4. 高影响点（Cook's Distance）
- 5个点超过阈值4/n=0.235:
  - MC_sq+[1,4]: D=1.52
  - MC_sq+[1,2]: D=0.64
  - diamond: D=0.50
  - triangular: D=0.45
  - kagome: D=0.44

### 5. 不同普适类
- FCC（密堆积）误差69% → 完全不同
- 复杂邻域可能有额外偏差
- (z,d,g)不唯一确定p_c

### 6. MC模拟的有限尺寸效应
- 正方晶格L=40: p_c=0.564 vs 精确解0.593（4.8%误差）
- MC模拟的统计噪声不可忽略
- 需要更多样本和更大尺寸

### 适用条件

**成立**:
- 标准晶格（SC, BCC, diamond, 超立方等）
- 2D和3D常见拓扑
- 非密堆积结构

**失效**:
- 密堆积结构（FCC）
- 相同(z,d,g)但不同连接距离的晶格
- 可能有其他"普适类"

### 科学定位

这不是PRL级别的"普适定律"，但是一个**有价值的工程近似**：

✓ 在适用范围内，预测误差~1-2%
✓ 揭示了(z,d,g)是渗流阈值的主导因素
✓ 为材料设计提供了快速估算工具
✓ 统计检验严格（AIC/BIC/Bootstrap/LOOCV）

- 需要高z但g≠4的晶格
- 例如: 高配位数但girth=3或girth=6的晶格

## 🎓 最终结论

经过7轮严谨验证，我们得出以下**诚实的科学结论**：

### 标度律是稳健的

在训练域内（标准晶格，排除FCC），标度律：
$$p_c \approx 2.28 \cdot z^{-0.82} \cdot d^{-0.74} \cdot \left(1 + \frac{1.49}{g}\right)$$

- R² = 0.994（稳健）
- MC数据再生验证: R² = 0.993（稳健）
- LOOCV R² = 0.988（无过拟合）
- AIC/BIC强证据支持

### 但有根本局限

1. α-B共线性（-0.944）→ 参数无法独立确定
2. 数据/参数比偏低（4.25）
3. 不同普适类（FCC偏离69%）
4. 高维晶格系统性偏差

### 科学定位

这不是PRL级别的"普适定律"，但是一个**有价值的工程近似**：

✓ 在适用范围内预测误差~1-2%
✓ 揭示了(z,d,g)是主导因素
✓ 为材料设计提供快速估算工具

### 诚实声明

渗流阈值可能**没有简单的普适公式**。
(z,d,g)是主导因素，但不唯一确定p_c。
需要更精细的物理量或理论框架。
