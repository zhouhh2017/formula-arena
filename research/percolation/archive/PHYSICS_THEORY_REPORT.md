# 物理理论驱动的渗流阈值分析

> **核心主张**: p_c 不是 (z, d) 的机械函数，而是由晶格的**物理结构**决定  
> **方法论**: 从统计物理、谱图论、概率论、信息论推导，而非黑箱拟合

---

## 🧠 理论基础

### 核心问题：p_c 由什么物理因素决定？

**直觉**: 渗流是"连通性"的相变。p_c 取决于：
1. 每个节点有多少邻居？→ **配位数 z**
2. 空间维度？→ **d** (控制关联长度)
3. 邻居之间是否重叠？→ **环结构** (girth, 三角形密度)
4. 图的谱性质？→ **谱半径, 谱间隙** (控制随机游走)

---

## 📊 关键物理量

为每个晶格计算/查找：

| 物理量 | 符号 | 物理含义 |
|--------|------|----------|
| 配位数 | z | 每个顶点的邻居数 |
| 维度 | d | 嵌入空间维度 |
| 最短环长度 | g (girth) | 环的最小尺度 |
| 每顶点三角形数 | n_tri | 三角形环密度 |
| 每顶点四边形数 | n_sq | 四边形环密度 |
| 聚类系数 | C | C = 2·n_tri / (z·(z-1)) |
| 有效配位数 | z_eff | z_eff = z - 2·n_tri/z (考虑重叠) |
| 平均面大小 | f_avg | 面大小的加权平均 |
| Bethe 近似 | p_B | p_B = 1/(z-1) |

## 🔬 8 个物理理论驱动的公式

### 理论 1: Bethe-Peierls + 环修正

**推导**:
```
Bethe 近似: 假设树状结构 (无环) → p_c = 1/(z-1)
但真实晶格有环 → 邻居重叠 → 有效配位数降低
每个三角形使 2 个邻居重叠 → z_eff = z - α·n_tri/z
修正: p_c = c / (z_eff - 1)
```

**物理含义**: 环使渗流更困难，因为部分路径是"冗余"的

**结果**: R² = 0.849, 训练 MAE = 0.078, LOOCV MAE = 0.093

---

### 理论 2: 谱图论 — 谱半径与聚类 ⭐ **最佳**

**推导**:
```
Nachmias & Peres (2008): 渗流阈值与图的谱性质密切相关
对正则图: λ₁ = z, 谱理论 → Bethe 近似
谱间隙 gap = z - λ₂ 控制关联长度 ξ
环结构影响 λ₂: 环越多 → gap 越小 → 关联越长 → p_c 越高
聚类系数 C 是谱间隙的代理量
预测: p_c = a / (z - b + c·C·z)
```

**物理含义**: 聚类 (三角形密度) 通过影响谱间隙来调制 p_c

**结果**:
- R² = 0.879, 训练 MAE = 0.075
- **LOOCV MAE = 0.040** ← **最佳!**
- 参数: a=2.24, b=0.04, c=-0.44

**解读**: 负 c 值说明聚类**降低** p_c (反直觉!)  
→ 三角形虽然减少独立路径，但也增强了局部连通性

---

### 理论 3: 随机游走 — 返回概率

**推导**:
```
渗流 ≈ 随机游走能否逃逸到无穷远
Pólya (1921): d≤2 常返, d>2 暂态
短环 (girth g) 增大返回概率: P_return ~ z^(1-g/2)
高返回 → 需要更高 p 才能渗流
预测: p_c = a·z^(-b)·(1 + c·z^(1-g/2))
```

**物理含义**: girth 越小 → 返回概率越高 → p_c 越高

**结果**: R² = 0.907, 训练 MAE = 0.064, LOOCV = 失败 (不稳定)

---

### 理论 4: 有效介质理论 (EMT) + 面大小

**推导**:
```
EMT (Kirkpatrick 1973): 随机网络 ≈ 均匀有效介质
键渗流: p_c^bond ≈ 2/d (高维精确)
Site 渗流需修正, 取决于配位壳层结构
面大小影响"冗余度": 大面 → 更多环 → 更高 p_c
预测: p_c = a / (z · d^b · (f_avg/3)^c)
```

**物理含义**: p_c 由"有效连接数" z·d^b·(f/3)^c 决定

**结果**:
- R² = 0.947, 训练 MAE = 0.040
- **LOOCV MAE = 0.047** ← 第二佳
- 参数: a=5.49, b=0.82, c=0.11

**解读**: 
- b ≈ 0.82 说明维度影响接近线性
- c ≈ 0.11 说明面大小影响微弱但正向

---

### 理论 5: 标度理论 — 上临界维度

**推导**:
```
上临界维度 d_c = 6: d≥6 平均场精确
有限维修正应指数衰减: ~ exp(-b·d)
预测: p_c = 1/(z-1) · (1 + a·exp(-b·d))
物理: Bethe 近似 + 有限维指数修正
```

**物理含义**: 低维 (d<6) 的 p_c 高于 Bethe 预测，修正项随 d 指数衰减

**结果**: R² = 0.871, 训练 MAE = 0.067, LOOCV MAE = 0.077

---

### 理论 6: 拓扑熵 — 信息论视角

**推导**:
```
信息论: p_c 编码晶格的"渗流复杂度"
复杂度 = 分支可能性 × 环约束
分支贡献: log(z) (每个节点 z 个选择)
环约束: -Σ n_face·log(face_size)/z
净拓扑熵: S = log(z) - n_tri·log(3)/z - n_sq·log(4)/z
预测: p_c ~ a/S + b (熵越低, p_c 越高)
```

**物理含义**: 拓扑熵度量"渗流自由度"，熵越低 → p_c 越高

**结果**: R² = 0.593, 训练 MAE = 0.117, LOOCV = 失败

---

### 理论 7: 综合多因子 ⭐ **训练最佳**

**推导**:
```
三因素协同:
(1) 配位数效应: ~ 1/z (Bethe)
(2) 环效应: clustering 度量环密度
(3) 维度效应: d 控制关联长度

统一公式:
p_c = A/(z^α · d^β) · (1 + B·C·z^γ)
```

**物理含义**:
- A/(z^α·d^β): 主标度项
- B·C·z^γ: 环修正 (环使邻居重叠)

**结果**:
- R² = 0.978, 训练 MAE = 0.028
- **LOOCV MAE = 失败** (过拟合, 5 参数 vs 21 点)

---

### 理论 8: Girth-Bethe 联合理论

**推导**:
```
Bethe 精确当且仅当 girth → ∞ (树状极限)
有限 girth → 环 → 修正
预测: p_c = a / ((z-1)^b · g^c · d^e)
```

**物理含义**: p_c 由 (z-1), girth, d 共同决定

**结果**:
- R² = 0.969, 训练 MAE = 0.032
- **LOOCV MAE = 0.048** ← 第三佳
- 参数: a=2.90, b=0.53, c=0.12, e=1.08

## 💡 核心洞察

### 1. **物理公式优于 ML**

- 谱理论+聚类: LOOCV MAE = 0.040 (3 参数)
- ML (7 物理特征): LOOCV MAE = 0.062 (7 参数)
- **物理公式性能是 ML 的 1.5 倍**, 且只有 3 个参数!

### 2. **三个最佳公式的物理共识**

**谱理论+聚类** (最佳):
```
p_c = 2.24 / (z - 0.04 - 0.44·C·z)
```
- 聚类 C 通过谱间隙影响 p_c
- 负系数说明聚类**增强**局部连通, **降低** p_c

**EMT+面大小** (第二):
```
p_c = 5.49 / (z · d^0.82 · (f_avg/3)^0.11)
```
- 有效连接数 = z · d^0.82 · (f_avg/3)^0.11
- 维度影响接近线性 (0.82 ≈ 1)
- 面大小影响微弱

**Girth-Bethe** (第三):
```
p_c = 2.90 / ((z-1)^0.53 · g^0.12 · d^1.08)
```
- Bethe 修正: (z-1)^0.53 而非 (z-1)^1
- Girth 影响微弱但正向
- 维度影响接近线性

### 3. **物理直觉的验证**

✓ **配位数 z**: 所有公式都确认 z 越大 → p_c 越小  
✓ **维度 d**: d 越大 → p_c 越小, 指数接近 1  
✓ **聚类 C**: 反直觉! C 越大 → p_c 越小 (增强局部连通)  
✓ **Girth g**: g 越大 → p_c 越小 (更接近 Bethe 极限)  

### 4. **为什么 ML 不如物理公式?**

ML 用 7 个特征但没有**物理约束**:
- 可能学到虚假相关
- 缺乏泛化能力
- 不可解释

物理公式用 3 个特征但**有物理约束**:
- 每个变量有明确含义
- 函数形式由理论指导
- 泛化更好

## 🎯 推荐公式

### 工程应用 (简单, 物理):

```
p_c ≈ 2.24 / (z · (1 - 0.44·C))
```

其中 C = 2·n_tri / (z·(z-1)) 是聚类系数

**物理含义**: p_c ≈ 2.24 / z_eff, 其中 z_eff = z·(1 - 0.44·C) 是考虑聚类后的有效配位数

### 更精确 (含维度):

```
p_c ≈ 5.49 / (z · d^0.82 · (f_avg/3)^0.11)
```

其中 f_avg 是平均面大小
