# 扫地僧符号回归发现报告

> 52 个真实数据点 | 符号回归 vs ML | LOOCV 严格验证

## 🏆 发现的新公式

### #1: ML 线性回归

```
w1·z + w2·d + w3/z + w4/d + w5·log(z) + w6·log(d) + b
```

- 参数数: 7
- 训练 MAE: 0.0325
- LOOCV MAE: 0.0325
- 类型: ML

### #2: Sigmoid校正

```
3.2207·z^(-0.9071)·d^(-0.4885)·(1+-0.2136·σ(4.3144·(d-2.5)))
```

- 参数数: 5
- 训练 MAE: 0.0301
- LOOCV MAE: 0.0326
- 类型: 符号回归

### #3: 幂律+常数 a·z^b·d^c+e

```
4.5319·z^(-0.9791)·d^(-0.9341)+0.0259
```

- 参数数: 4
- 训练 MAE: 0.0301
- LOOCV MAE: 0.0333
- 类型: 符号回归

### #4: 基础幂律 a·z^b·d^c

### #5: 双幂律 a·z^b·d^c+e·z^f·d^g

## 💡 结论

1. 扫地僧找到了多个优于基础幂律的公式
2. 最佳公式: w1·z + w2·d + w3/z + w4/d + w5·log(z) + w6·log(d) + b
3. LOOCV MAE = 0.0325 vs ML 的 0.0325
4. 参数数 7 vs ML 的 7, 可解释性更强
